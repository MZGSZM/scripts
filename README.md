# Scripts

A personal collection of single-purpose, standalone scripts, sorted into folders by **platform compatibility**.

## Structure

| Folder | Contents |
|---|---|
| [`agnostic/`](./agnostic/README.md) | Scripts that run unmodified on Linux, Windows, and macOS. |
| `linux/` | *(planned)* Scripts that depend on Linux-only tools, paths, or package managers. |
| `windows/` | *(planned)* Scripts that depend on Windows-only tools (PowerShell, `.bat`, registry access, etc.). |
| `macos/` | *(maybe)* Scripts that depend on macOS-only tools (`launchd`, `osascript`, Homebrew, etc.). |

Each folder has its own `README.md` listing what's in it. Templates for new folder READMEs live in [`templates/`](./templates/).
